# #31 — Fix missing `@testing-library/dom` dependency breaking `RoleEscrowDashboard.test.tsx`

## Summary
`apps/frontend/src/components/dashboard/RoleEscrowDashboard.test.tsx` fails to run:

```
Cannot find module '@testing-library/dom' from '.../node_modules/@testing-library/react/dist/pure.js'
```

## Root cause
`@testing-library/react` (see `apps/frontend/package.json`) depends on `@testing-library/dom` as a peer dependency, but it is never listed as an explicit dependency anywhere in the project — confirmed absent from `yarn.lock` even before the monorepo restructuring, so this predates that change.

## Fix
Add `@testing-library/dom` to `apps/frontend/package.json`'s `devDependencies` at a version compatible with the installed `@testing-library/react@16.3.2`, then re-run `yarn install`.

## Acceptance criteria
- [ ] `yarn workspace @truestub/frontend test` runs `RoleEscrowDashboard.test.tsx` successfully.
- [ ] `tsc --noEmit` no longer errors on the missing module in this file.
