# #33 — Add the missing ESLint configuration file

## Summary
`apps/frontend/package.json`'s `lint` script runs `eslint . --cache`, and `eslint`, `eslint-config-next`, `eslint-config-prettier`, and `@eslint/eslintrc` are all installed — but no ESLint config file (`eslint.config.mjs`, `.eslintrc.*`) exists anywhere in the repo.

## Impact
`yarn lint` currently has nothing to actually configure rules with, so lint either no-ops or errors depending on the ESLint version's defaults.

## Fix
Add `apps/frontend/eslint.config.mjs` extending `eslint-config-next` and `eslint-config-prettier`, matching the flat-config format ESLint 9 (already a dependency) expects.

## Acceptance criteria
- [ ] `yarn workspace @truestub/frontend lint` runs real rules and reports real violations.
- [ ] CI (once #36 exists) can gate PRs on lint passing.
